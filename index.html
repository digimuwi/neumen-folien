WIP: Handschrift → MEI-Kodierung

Morent / Böttiger / Pfeffer
  • ML-Modell zur Segmentierung und Neumenerkennung wurde mit eigenen Annotationen trainiert
  • Texterkennung basiert auf dem Modell TRIDIS
  • Gesamtpipeline ist noch in Entwicklung – in Zukunft hoffentlich gemeinsam mit ELLIS

1.545 Prompts / 264 Sitzungen / 30,7M Tokens / 120.000 Codezeilen

  • Coding-Assistenten erlauben direkte Umsetzung und Weiterentwicklung von noch nicht konkreten Ideen
  • Mithilfe von Claude Code können neue, eigenständige Modelle (etwa zur Neumenerkennung oder -klassifizierung) entwickelt und trainiert werden
  • Innerhalb des gezeigten Workflows zur Neumenerkennung können Sprachmodelle auch zur Korrektur von OCR-Fehlern eingesetzt werden
  • Mehrmonatige Entwicklungszeiten können auf wenige Tage reduziert werden
  • Sauberer Quelltext, mit richtigen Prompts kaum „AI Slop“
  • (Unter aktuellen Bedingungen) Abhängigkeit von kommerziellen Anbietern
  • Geschlossenes System: keine vollständige Kenntnis des Quelltextes mehr. Weiterbearbeitung erzwingt Weiterverwendung von KI-Coding-Assistenten.
